void automaticMode ( const wchar_t *  filePath,
unsigned int  address,
unsigned int  skipErase,
unsigned int  verify,
int  isMassErase,
char *  obCommand,
int  run 
)

This routine allows to enter and make an automatic process for memory management through JTAG/SWD, UART, DFU, SPI, CAN and I²C interfaces.

Parameters
filePath: Indicates the full file path.
address: The address to start downloading from.
skipErase: If we have a blank device, we can skip erasing memory before programming [skipErase=0].
verify: Add verification step after downloading.
isMassErase: Erase the whole Flash memory.
obCommand: Indicates the option bytes commands to be loaded "-ob [optionbyte=value] [optionbyte=value]..."
run: Start the application.
Warning
Connection to target must be established before performing automatic mode.

This routine allows to download data from a file to the memory. File formats that are supported : hex, bin, srec, tsv, elf, axf, out, stm32, ext.

Parameters
filePath: Indicates the full path of the considered file.
address: The address to start downloading from.
skipErase: In case to win in term time and if we have a blank device, we can skip erasing memory before programming [skipErase=0].
verify: To add verification step after downloading.
binPath: Path of the binary file.
Returns
0 if the downloading operation correctly finished, otherwise an error occurred.
Examples
CAN_Bootloader, I2C_Bootloader, SPI_Bootloader, STLINK_Example2, STLINK_Example3, TSV_Flashing, UART_Bootloader, and USB_Bootloader.

)

This routine allows to enter and make an automatic process for memory management with serial numbering through JTAG/SWD, UART, DFU, SPI, CAN and I²C interfaces.

Parameters
filePath: Indicates the full file path.
address: The address to start downloading from.
skipErase: If we have a blank device, we can skip erasing memory before programming [skipErase=0].
verify: Add verification step after downloading.
isMassErase: Erase the whole Flash memory.
obCommand: Indicates the option bytes commands to be loaded "-ob [optionbyte=value] [optionbyte=value]..."
run: Start the application.
enableSerialNumbering: enables the serial numbering.
serialAddress: the address where the inital data and the subsequent increments will be made.
serialSize: size for the serial numbering.
serialInitialData: intial data used for the serial numbering that will be incremented.
Warning
Connection to target must be established before performing automatic mode with serial numbering.
