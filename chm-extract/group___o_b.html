int sendOptionBytesCmd ( char *  command)

This routine allows program the given Option Byte. The option bytes are configured by the end user depending on the application requirements.

Parameters
command: Indicates the command to execute.
Returns
0 if the programming Option Byte correctly executed, otherwise an error occurred.
Note
The command must written as: -ob [optionbyte=value] [optionbyte=value] ...
int ob = sendOptionBytesCmd("–ob rdp=0x0 BOR_LEV=0");
