Detailed Description

Specify the CAN connect parameters.

Note
Not all configurations are supported by STM32 Bootloader, such as CAN type is STANDARD and the filter should be always activated.
Recommended CAN parameters : br=125000, mode=0, ide=0, rtr=0, fifo=0, fm=0, fs=1, fe=1, fbn=0

CAN_Bootloader.
