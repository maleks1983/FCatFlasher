Detailed Description

Specific APIs used exclusively for STM32WB series to manage BLE Stack and they are available only through USB DFU and UART bootloader interfaces, except for the “firmwareDelete" and the “firmwareUpgrade", available through USB DFU, UART and SWD interfaces. Connection under Reset is mandatory.

This routine allows to make upgrade of BLE stack firmware or FUS firmware.

Parameters
filePath: Indicates the full path of the firmware to be programmed.
address: Start address of download.
firstInstall: 1 if it is the first installation, otherwise 0, to ignore the firmware delete operation.
startStack: Starts the stack after programming.
verify: Verify if the download operation is achieved successfully before starting the upgrade.
Returns
true if the operation was acheived successfully, otherwise an error occurred.
