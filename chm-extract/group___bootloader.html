Detailed Description

Bootloader module is a way to group Serial interfaces USB/UART/SPI/I2C/CAN functions together.

This routine allows to get connected DFU devices.

Parameters
dfuList: Receive DFU devices list and its default configurations.
iPID: Indicate the Product ID to be used for DFU interface.
iVID: Indicate the Vendor ID to be used for DFU interface.
Returns

Note
At the end of usage, deleteInterfaceList must have been called.
Examples
MPU_SSP, TSV_Flashing, and USB_Bootloader.
